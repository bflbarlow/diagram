# Code Review — 2026-09-15

Scope: `index.html`, `app.js` (v1.1.5, 3,499 lines), `styles.css`, `about/index.html`.

Overall: solid vanilla-JS canvas editor. Proper input escaping, try/catch around
localStorage, event delegation (no listener leaks), capped undo (50) and log
(500), correct BroadcastChannel multi-tab tiebreaker, decent a11y
(skip-link, `aria-live`, `role`). Issues below.

## Real bugs

### 1. Layers tab highlight is dead code
- `app.js:1266` — `renderLayouts()` checks `S.selectedIds`, which is never
  defined anywhere. State uses `S.selection`.
- Effect: the "active" highlight on layer rows in the Layers tab never works.
- Fix: `var isSelected = S.selection.indexOf(s.id) !== -1;`

### 2. Unclamped zoom on file import
- `app.js` (~3169, `btnLoadFile` handler) — `S.zoom = d.zoom` is set raw from
  the imported `.json`. A bad file (zoom 0 or 999) breaks the view.
- The localStorage load path clamps to `CONFIG.minZoom`/`CONFIG.maxZoom`;
  the import path doesn't.
- Fix: reuse the same clamp check as `loadFromLocalStorage()`.

## Hygiene

### 3. `.DS_Store` tracked in git, no `.gitignore`
- `git ls-files` shows `.DS_Store`; `git status` is permanently dirty.
- Fix: add a `.gitignore` (`.DS_Store`), `git rm --cached .DS_Store`.

### 4. `scheduleSave()` double-writes
- `app.js:385` — calls `saveState()` immediately *and* schedules the 300ms
  debounced save. Every action does two localStorage writes; the immediate
  call defeats the debounce.
- Fix: drop the immediate call, keep only the debounced one (or vice versa).

### 5. Version drift
- `README.md` still says v1.1.4; `app.js` and `about/index.html` say 1.1.5.
- Fix: bump README title + "Version" line + add a 1.1.5 changelog entry.

### 6. Minor code smells
- `renderLayouts()`: `var html` declared twice.
- `escHtml()` doesn't escape quotes — safe today (only used in text-content
  contexts, `app.js:118` and `app.js:1270`) but a landmine if ever used in
  an attribute position.

## Verified fine
- JSON import validation (types checked, old-file property backfill)
- Undo/redo (maxUndo 50, JSON snapshots)
- BroadcastChannel claim/deny/release flow + deterministic tiebreaker
- XSS surface: user names escaped via `escHtml`; generated ids are internal
- A11y: skip-link, `aria-live` log, `sr-only` h1, keyboard shortcuts
